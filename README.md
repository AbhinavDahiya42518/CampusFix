# CampusFix
CampusFix - Campus Issue Reporting and Tracking System

CampusFix – Campus Issue Reporting and Tracking System
  **A Smart Campus Problem Reporting Solution**

CampusFix is a campus issue reporting and tracking system designed to make it easier for students to report campus problems and monitor their resolution.

It combines a C-based application with a modern website to present the project as a complete solution.

Problem Statement

Students may face difficulties reporting campus issues and knowing whether those issues have been addressed. CampusFix aims to provide a structured platform for reporting and tracking these problems.

Project Components

1. C Application

- Developed using C.
- Source code: "c-app/CampusFix.c"
- Complaint data: "c-app/complaints.dat"
- Compiled executable: "c-app/campusfix.exe"

2. Website

- Modern web interface.
- Built using TypeScript and web technologies.
- Source code available in the "Website" directory.

3. Project Presentation

- Complete project presentation available in "presentation".
